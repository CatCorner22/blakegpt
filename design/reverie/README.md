# Reverie character studio

Reverie is Focus’s gentle cream-and-ginger cat guide. Her name means **a pleasant daydream**. This curated copy keeps character references separate from app code.

Start with `START-HERE.md`, then use `FIRST-MESSAGE.txt` when opening a character-focused chat. This folder does not create a chat or account-wide memory.

- `reference/`: approved aim-and-imagine character board.
- `logos/`: Focus, Vision, Horizon, Telescope and Target lockups.
- `stickers/`: approved original transparent poses, including her kite and red rocket ride.
- `knowledge/`: portable Cat Samurai principle and character guidance.
- `code/`: selected reference source, with exact commit and hashes in provenance.json. It is not a standalone application.

The approved original artwork is copied without alteration. The generated map-reading pose from the source package is omitted because it has no separate owner approval. No app surface is recolored beige; Reverie’s approved fur remains cream-and-ginger.

These PNGs can be inputs to future sticker projects. This folder is not an installed iPhone sticker pack. Device import, sizing and App Store packaging have not been performed.

Run `python verify.py` to compare every copied file with `SHA256SUMS.txt`. The inventory establishes byte integrity, not image rights, visual quality or runtime behavior.
