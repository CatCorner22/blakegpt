# Reverie character references

This folder holds approved character references for Reverie, Focus’s gentle cream-and-ginger cat guide.

1. Read `ABOUT-REVERIE.md` and `character-guide.md`.
2. Review `reference/reverie-approved-aim-and-imagine-board.png` and the approved artwork.
3. Use `FIRST-MESSAGE.txt` as context when opening a character-focused chat.

This folder does not create or synchronize a chat. The generated map-reading pose from the source package is omitted because it has no separate owner approval.

The `code` folder contains selected Focus reference files, not a standalone app. Do not install it over Focus or run it as a project. For a new illustration, inspect the approved reference board and match Reverie’s identity: cream-and-ginger fur, forest-green outlines, a warm expression and a gentle character.
