# Focus reference code

These selected files were copied byte-for-byte from the commit in provenance.json. They show how Focus uses Reverie, onboarding, the Garden Path, Stratosphere and supporting tests. This folder is not a standalone application: it deliberately lacks the complete router, dependencies, services and build configuration. Do not copy it over Focus or assume its imports resolve on their own.

The original source files and historical release notes are reference material. Any release claims within copied notes apply to their original historical scope, not to this folder or to a current deployment. The source snapshot precedes the next Garden interface update. The generated map-reading pose from the source package is omitted from this public reference copy because it has no separate owner approval.

Focus’s existing images and source remain in place. A future character-only chat can inspect these files without changing Focus.
